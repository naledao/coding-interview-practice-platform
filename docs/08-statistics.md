# 功能：学习统计

## 1. 功能目标

学习统计帮助用户了解刷题进度、正确率和薄弱知识点，也帮助后续推荐和复习功能打基础。

## 2. 用户故事

作为用户，我希望看到自己总共刷了多少题、正确率是多少、哪些标签掌握较差，以便调整复习计划。

## 3. 功能范围

### P0

- 总答题数。
- 总正确数。
- 总错误数。
- 总正确率。
- 今日答题数。
- 错题数量。
- 收藏数量。

### P1

- 按标签统计正确率。
- 最近 7 天答题数量。
- 连续刷题天数。

### P2

- 薄弱知识点推荐。
- 学习趋势图。
- 目标计划。
- 排名。

## 4. 统计首页

展示：

- 总答题数。
- 正确率。
- 今日答题数。
- 错题数。
- 收藏数。
- 连续刷题天数。

交互：

- 点击错题数进入错题本。
- 点击收藏数进入收藏列表。
- 点击标签统计进入标签详情。

## 5. 标签统计

展示：

- 标签名称。
- 已答题数。
- 正确数。
- 错误数。
- 正确率。

排序：

- 默认按已答题数倒序。
- 可选按正确率升序，用于发现薄弱标签。

## 6. 统计口径

### 总答题数

用户所有答题记录数量。

### 总正确数

答题记录中 `isCorrect=true` 的数量。

### 总错误数

答题记录中 `isCorrect=false` 的数量。

### 正确率

```text
正确率 = 总正确数 / 总答题数
```

如果总答题数为 0，正确率显示为 0。

### 今日答题数

按用户本地或系统配置时区统计当天答题记录数量。

### 错题数量

错题本中 `mastered=false` 的题目数量。

### 收藏数量

当前收藏题目数量。

## 7. 接口

### 统计概览

`GET /api/statistics/overview`

响应：

```json
{
  "answeredTotal": 120,
  "correctTotal": 92,
  "wrongTotal": 28,
  "accuracy": 0.7667,
  "todayAnswered": 20,
  "wrongBookCount": 18,
  "favoriteCount": 15,
  "streakDays": 3
}
```

### 标签统计

`GET /api/statistics/tags`

响应项：

```json
{
  "tagId": 1,
  "tagName": "JVM",
  "answeredTotal": 30,
  "correctTotal": 21,
  "wrongTotal": 9,
  "accuracy": 0.7
}
```

### 最近 7 天统计

`GET /api/statistics/daily?days=7`

响应项：

```json
{
  "date": "2026-06-29",
  "answeredTotal": 20,
  "correctTotal": 16
}
```

## 8. 缓存规则

一期可以实时查询。

后续如果数据量变大：

- 用户统计概览可缓存 1 到 5 分钟。
- 标签统计可异步聚合。
- 每日统计可按天预聚合。

## 9. 异常规则

- 用户未登录：返回 401。
- 没有答题记录：返回 0 值统计。
- 查询天数非法：使用默认值或返回参数错误。

## 10. 验收标准

- 新用户统计显示为 0。
- 用户答题后总答题数增加。
- 答对后正确数增加。
- 答错后错误数增加。
- 今日答题数按当天记录统计。
- 标签统计能反映用户在各标签下的正确率。
