# 功能：登录、角色与权限

## 1. 功能目标

系统需要区分普通用户和管理员。普通用户进入刷题功能，管理员进入文档上传、导入任务监控和题库管理功能。

## 2. 用户故事

### 普通用户

作为准备 Java 面试的用户，我希望登录后可以进入 APP 首页，继续刷题、查看错题和统计。

### 管理员

作为管理员，我希望登录后可以上传 Markdown 文档并查看 Codex 产题任务状态。

## 3. 功能范围

### P0

- 邮箱验证码登录。
- 管理员通过管理员邮箱登录。
- 获取当前登录用户信息。
- 登录状态保持。
- 退出登录。
- 基于角色限制接口访问。

### P1

- 修改昵称。
- 登录失败次数限制。

## 4. 页面功能

### 登录页

字段：

- 邮箱。
- 验证码。

按钮：

- 登录。

交互：

- 点击获取验证码后调用发送验证码接口。
- 点击登录后调用登录接口。
- 登录成功后保存 token。
- 普通用户跳转用户首页。
- 管理员跳转管理首页。
- 登录失败时展示错误提示。

### 我的页

展示：

- 昵称。
- 邮箱。
- 当前角色。
- 总答题数。
- 正确率。

操作：

- 修改昵称。
- 退出登录。

## 5. 权限规则

### 普通用户可访问

- 刷题接口。
- 标签接口。
- 题目详情接口。
- 答题接口。
- 错题本接口。
- 收藏接口。
- 统计接口。

### 管理员可访问

- 文档上传接口。
- 文档列表接口。
- 导入任务接口。
- 题库管理接口。
- 普通用户可访问的部分只读接口。

### 未登录用户可访问

- 发送登录验证码接口。
- 登录接口。
- 健康检查接口。

## 6. 接口

### 发送登录验证码

`POST /api/auth/send-login-code`

请求：

```json
{
  "email": "admin@example.com"
}
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": null
}
```

### 登录

`POST /api/auth/login`

请求：

```json
{
  "email": "admin@example.com",
  "code": "123456"
}
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "token": "jwt-token",
    "user": {
      "id": 1,
      "email": "admin@example.com",
      "nickname": "管理员",
      "role": "ADMIN"
    }
  }
}
```

### 当前用户

`GET /api/auth/me`

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "email": "user1@example.com",
    "nickname": "用户",
    "role": "USER"
  }
}
```

### 修改昵称

`PATCH /api/auth/me/nickname`

请求：

```json
{
  "nickname": "新昵称"
}
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "email": "user1@example.com",
    "nickname": "新昵称",
    "role": "USER"
  }
}
```

### 退出登录

`POST /api/auth/logout`

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": null
}
```

## 7. 异常规则

- 邮箱或验证码为空：提示“请输入邮箱和验证码”。
- 邮箱格式错误：提示“邮箱格式不正确”。
- 验证码错误或过期：提示“验证码错误或已过期”。
- 同一邮箱连续登录失败 5 次后临时锁定 300 秒，锁定期间返回 429，并提示“登录失败次数过多，请稍后再试”。
- 昵称为空：提示“昵称不能为空”。
- 昵称超过 64 个字符：提示“昵称不能超过64个字符”。
- 用户被禁用：提示“账号已被禁用”。
- token 过期：清理本地登录态并跳转登录页。
- 无权限访问管理员接口：返回 403。

## 8. 数据要求

用户字段：

- `id`
- `email`
- `nickname`
- `role`
- `status`
- `createdAt`
- `updatedAt`

角色：

- `USER`
- `ADMIN`

状态：

- `ACTIVE`
- `DISABLED`

## 9. 验收标准

- 普通用户登录后进入用户首页。
- 管理员登录后可以进入管理功能。
- 未登录访问刷题接口返回 401。
- 普通用户访问管理员接口返回 403。
- 退出登录后不能继续访问需要登录的接口。
- 登录失败次数达到限制后临时锁定，并返回 429。
- 登录用户可以在我的页修改昵称，刷新当前用户信息后展示新昵称。
