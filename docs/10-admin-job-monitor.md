# 功能：导入任务监控

## 1. 功能目标

管理员可以查看 Markdown 文档导入任务的执行状态、Codex 日志、生成题目数量和失败原因，并对失败任务进行重试。

## 2. 用户故事

作为管理员，我希望上传文档后能看到 Codex 是否正在处理、处理成功生成了多少题，以及失败时为什么失败。

## 3. 功能范围

### P0

- 导入任务列表。
- 导入任务详情。
- 任务状态展示。
- 生成题目数量展示。
- 失败原因展示。
- 任务日志展示。

### P1

- 失败任务重试。
- 正在运行任务刷新状态。
- 查看本任务生成的题目。

### P2

- 取消运行中任务。
- 批量重试。
- 任务耗时统计。
- Codex 事件流实时展示。

## 4. 页面功能

### 导入任务列表页

展示：

- 任务 ID。
- 文档名称。
- 状态。
- 生成题目数量。
- 开始时间。
- 结束时间。
- 失败原因摘要。

筛选：

- 状态。
- 文档名称。
- 创建时间。

操作：

- 查看详情。
- 重试失败任务。

### 导入任务详情页

展示：

- 任务基础信息。
- 文档信息。
- 当前状态。
- Codex session ID。
- 生成题目数量。
- 开始时间。
- 结束时间。
- 失败原因。
- 日志列表。
- 本任务生成的题目列表。

操作：

- 刷新状态。
- 重试。
- 查看题目详情。

## 5. 状态展示规则

### PENDING

展示：

- “等待执行”。

可操作：

- 刷新。

### RUNNING

展示：

- “Codex 正在处理”。
- 当前已生成题目数量。
- 最近日志。

可操作：

- 刷新。

### SUCCEEDED

展示：

- “处理成功”。
- 生成题目数量。
- 本任务生成题目入口。

可操作：

- 查看题目。

### FAILED

展示：

- “处理失败”。
- 失败原因。
- 错误日志。

可操作：

- 重试。

### CANCELLED

展示：

- “已取消”。

一期可以不支持取消，只保留状态枚举。

## 6. 接口

### 任务列表

`GET /api/admin/import-jobs?page=1&pageSize=20&status=RUNNING`

响应项：

```json
{
  "id": 2001,
  "documentId": 1001,
  "documentName": "jvm.md",
  "status": "RUNNING",
  "generatedQuestionCount": 3,
  "failedReason": null,
  "startedAt": "2026-06-29 10:00:00",
  "finishedAt": null,
  "createdAt": "2026-06-29 09:59:50"
}
```

### 任务详情

`GET /api/admin/import-jobs/{jobId}`

### 任务日志

`GET /api/admin/import-jobs/{jobId}/logs`

响应项：

```json
{
  "id": 1,
  "level": "INFO",
  "message": "提取到 8 个知识点",
  "payload": {
    "knowledgePoints": ["JVM内存区域", "GC Roots"]
  },
  "createdAt": "2026-06-29 10:01:00"
}
```

### 本任务生成题目

`GET /api/admin/import-jobs/{jobId}/questions?page=1&pageSize=20`

### 重试任务

`POST /api/admin/import-jobs/{jobId}/retry`

响应：

```json
{
  "newImportJobId": 2002,
  "status": "PENDING"
}
```

## 7. 重试规则

- 只有 `FAILED` 任务可以重试。
- 重试时创建新任务，不复用旧任务 ID。
- 新任务关联同一个文档。
- 旧任务日志保留。
- 新任务独立记录日志和产题数量。

## 8. 日志规则

Codex 和 MCP 应记录：

- 任务开始。
- 文档读取成功。
- 提取到的知识点数量。
- 联网搜索摘要。
- 生成题目数量。
- 自我 review 丢弃题目数量。
- 写入题目数量。
- 失败原因。

日志级别：

- `INFO`
- `WARN`
- `ERROR`

## 9. 异常规则

- 任务不存在：返回 404。
- 非失败任务重试：返回状态冲突。
- 日志为空：展示“暂无日志”。
- Codex 进程异常退出：任务标记失败并记录退出码。

## 10. 验收标准

- 管理员可以看到导入任务列表。
- 任务状态会随 Codex 执行更新。
- 成功任务显示生成题目数量。
- 失败任务显示失败原因。
- 管理员可以查看任务日志。
- 失败任务可以重试并创建新任务。
