# 功能：错题本与收藏

## 1. 功能目标

错题本帮助用户复习答错的题目，收藏帮助用户保存重点题。两个功能都是刷题产品的核心复习入口。

## 2. 用户故事

作为用户，我希望答错的题自动进入错题本，方便之后集中复习。

作为用户，我希望可以收藏重要题目，之后快速找到并重新练习。

## 3. 功能范围

### P0

- 答错自动加入错题本。
- 错题列表。
- 错题重新练习。
- 收藏题目。
- 取消收藏。
- 收藏列表。

### P1

- 标记错题已掌握。
- 移除错题。
- 收藏练习模式。
- 错题练习模式。

### P2

- 错题按标签统计。
- 连续答对自动掌握。
- 收藏分组。

## 4. 错题本规则

### 加入错题本

用户提交错误答案时：

- 如果错题本没有该题，创建错题记录。
- 如果错题本已有该题，增加错误次数。
- 更新最近答错时间。
- 设置 `mastered=false`。

### 答对错题

用户答对错题时：

- 增加错题答对次数。
- 更新最近答题时间。
- 一期不自动移除错题。

### 标记掌握

用户可以手动标记掌握。

标记后：

- `mastered=true`。
- 默认不出现在未掌握错题列表。
- 历史记录保留。

### 移除错题

用户可以从错题本移除题目。

移除后：

- 不再出现在错题本。
- 答题历史不删除。
- 以后再次答错会重新加入。

## 5. 收藏规则

### 收藏题目

用户可以在以下位置收藏：

- 刷题页。
- 题目详情页。
- 错题本。
- 搜索结果。

收藏要求：

- 同一用户同一题只能收藏一次。
- 重复收藏接口保持成功。

### 取消收藏

取消收藏后：

- 题目不再出现在收藏列表。
- 答题记录不受影响。

## 6. 页面功能

### 错题本页

展示：

- 题干摘要。
- 标签。
- 难度。
- 错误次数。
- 最近答错时间。
- 是否已掌握。

操作：

- 开始错题练习。
- 查看题目。
- 标记掌握。
- 移除错题。

筛选：

- 未掌握。
- 已掌握。
- 全部。

### 收藏页

展示：

- 题干摘要。
- 标签。
- 难度。
- 收藏时间。

操作：

- 开始收藏练习。
- 查看题目。
- 取消收藏。

## 7. 接口

### 错题列表

`GET /api/wrong-questions?page=1&pageSize=20&mastered=false`

响应项：

```json
{
  "questionId": 1,
  "stem": "关于 Java volatile 的说法，哪一项是正确的？",
  "difficulty": "MEDIUM",
  "tags": ["Java并发", "JMM"],
  "wrongCount": 2,
  "correctAfterWrongCount": 1,
  "mastered": false,
  "lastWrongAt": "2026-06-29 10:00:00"
}
```

### 标记掌握

`POST /api/wrong-questions/{questionId}/master`

### 取消掌握

`POST /api/wrong-questions/{questionId}/unmaster`

### 移除错题

`DELETE /api/wrong-questions/{questionId}`

### 收藏题目

`POST /api/favorites/{questionId}`

### 取消收藏

`DELETE /api/favorites/{questionId}`

### 收藏列表

`GET /api/favorites?page=1&pageSize=20`

## 8. 异常规则

- 题目不存在：提示“题目不存在或已下线”。
- 重复收藏：返回成功。
- 取消未收藏题目：返回成功。
- 标记不存在的错题：返回 404 或自动创建后标记，推荐返回 404。

## 9. 验收标准

- 用户答错后错题本出现该题。
- 同一题多次答错会增加错误次数。
- 用户可以标记掌握。
- 已掌握题默认不出现在未掌握列表。
- 用户可以收藏题目。
- 重复收藏不会产生重复数据。
- 用户可以取消收藏。
