# 功能：题库与标签

## 1. 功能目标

题库保存 Codex 生成的单选题，并为用户刷题、搜索、错题、收藏和统计提供基础数据。

## 2. 用户故事

作为用户，我希望题目有清晰题干、选项、答案解析和标签，方便我按知识点刷题。

作为管理员，我希望可以查看题库内容，并在发现明显问题时下线题目。

## 3. 功能范围

### P0

- 保存单选题。
- 保存选项。
- 保存正确答案。
- 保存答案解析。
- 保存标签。
- 查询题目列表。
- 查询题目详情。
- 管理员下线题目。

### P1

- 题目搜索。
- 按难度筛选。
- 按标签筛选。
- 题目正确率统计。

### P2

- 题目质量分。
- 相似题合并。
- 标签别名。
- 题目版本。

## 4. 题目字段

题目包含：

- 题目 ID。
- 题型。
- 题干。
- 选项。
- 正确答案。
- 解析。
- 难度。
- 标签。
- 知识点。
- 来源文档。
- 来源导入任务。
- Codex review 摘要。
- 状态。
- 创建时间。

题型一期固定：

- `SINGLE_CHOICE`

## 5. 标签字段

标签包含：

- 标签 ID。
- 标签名称。
- 归一化名称。
- 标签分类。
- 题目数量。

推荐标签：

- `Java基础`
- `面向对象`
- `异常处理`
- `Java集合`
- `泛型`
- `JVM`
- `类加载`
- `垃圾回收`
- `Java并发`
- `JMM`
- `线程池`
- `锁`
- `Spring`
- `Spring Boot`
- `MyBatis`
- `MySQL`
- `Redis`
- `网络`
- `设计模式`
- `分布式`

## 6. 用户端题目列表

入口：

- 首页推荐。
- 标签详情。
- 搜索结果。
- 收藏。
- 错题本。

展示：

- 题干摘要。
- 难度。
- 标签。
- 是否已答。
- 是否收藏。

不展示：

- 正确答案。
- 答案解析。

## 7. 用户端题目详情

未答题前展示：

- 题干。
- 选项。
- 难度。
- 标签。
- 收藏状态。

答题后展示：

- 用户选择。
- 正确答案。
- 是否正确。
- 答案解析。

## 8. 管理员题库列表

展示：

- 题目 ID。
- 题干摘要。
- 难度。
- 标签。
- 状态。
- 来源文档。
- 来源任务。
- 创建时间。

操作：

- 查看详情。
- 下线题目。
- 恢复题目。

一期不提供人工编辑题目，避免和“Codex 自产题”流程混在一起。后续可以增加编辑能力。

## 9. 接口

### 用户题目列表

`GET /api/questions?page=1&pageSize=20&tagId=1&difficulty=MEDIUM&keyword=jvm`

### 题目详情

`GET /api/questions/{questionId}`

响应：

```json
{
  "id": 1,
  "type": "SINGLE_CHOICE",
  "stem": "关于 Java HashMap 的说法，哪一项是正确的？",
  "difficulty": "MEDIUM",
  "options": [
    {
      "id": 11,
      "optionKey": "A",
      "content": "HashMap 是线程安全的"
    }
  ],
  "tags": [
    {
      "id": 1,
      "name": "Java集合"
    }
  ],
  "favorite": false,
  "answered": false
}
```

### 标签列表

`GET /api/tags`

响应项：

```json
{
  "id": 1,
  "name": "JVM",
  "category": "JAVA",
  "questionCount": 30
}
```

### 管理员题目列表

`GET /api/admin/questions?page=1&pageSize=20&status=ACTIVE`

### 下线题目

`POST /api/admin/questions/{questionId}/disable`

### 恢复题目

`POST /api/admin/questions/{questionId}/enable`

## 10. 状态规则

- `ACTIVE` 题目可以被用户刷到。
- `DISABLED` 题目不会出现在用户刷题列表。
- 管理员可以查看所有状态题目。
- 用户历史答题记录不因题目下线而删除。

## 11. 异常规则

- 题目不存在：返回 404。
- 题目已下线且普通用户访问：返回 404 或不可用提示。
- 标签不存在：返回空列表或 404，按接口语义决定。
- 查询参数非法：返回参数错误。

## 12. 验收标准

- Codex 写入的题目可以在题库查询到。
- 用户题目列表不泄露正确答案。
- 答题后可以看到解析。
- 标签列表展示题目数量。
- 下线题目不会被用户刷到。
